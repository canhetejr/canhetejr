## O que eu faço

Trabalho no cruzamento entre **educação digital, design, operação e tecnologia**.

No dia a dia, isso vira Moodle organizado, disciplina estruturada, banco de questões convertido, fluxo automatizado, planilha que para de ser sofrimento, interface interna que resolve uma dor real e pequenas ferramentas que economizam horas de trabalho repetitivo.

Minha lógica é simples: entender o processo, desenhar o fluxo, automatizar o que pesa, criar interface quando precisa e documentar para ninguém depender de lenda oral.

## Minha forma de construir

```txt
entrada:
  problema bagunçado, planilha gigante, rotina manual ou demanda urgente

processo:
  mapear → simplificar → automatizar → testar → ajustar → documentar

saída:
  ferramenta útil, fluxo mais leve e operação menos dependente de improviso
```

Gosto de solução com cara de coisa viva: simples de usar, possível de manter e forte o bastante para sobreviver à segunda-feira.
